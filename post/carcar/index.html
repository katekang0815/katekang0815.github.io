Car Car

A CRUD app that allows car dealers to manage inventory, technicians to track services, and customers to create service requests. Enhanced backend RESTful API endpoints to optimize data delivery and React hooks to manage stateful components.

Tech stack #

Django REST framework, Python, JavaScript, PostgreSQL, Docker, React, RESTful APIs

GHI Design #

The three services intersect at a point represented by an Automobile. Each microservice interprets and focuses on it differently.

  • Within Auto Services microservice, an Automobile is represented by whether it has been sold by the dealership. If so, it is considered VIP.
  • In Auto Sales microservice, it focuses on availability in inventory to determine if the automobile can be sold.
  • In Inventory microservice, it emphasizes descriptive properties like color, year, and picture.

Vehicle Models List #

  • This page lists all vehicle models.

Create a Service Appointment #

  • ServiceAppointmentForm
    • Form for service concierges to enter VIN, owner, date/time, assigned technician, and reason for service.
    • On submission, the appointment is saved in the app.
    • Navbar link to access this form.

  • List of Appointments
    • Displays VIN, customer name, appointment time, technician, and reason for service.
    • Includes cancel/finish buttons.
    • Marks VIP if car exists in inventory.

  • ServiceHistory
    • VIN input to look up service history.
    • Fetches all appointments for that VIN.
    • Displays appointment details.
    • Navbar link to access history page.
