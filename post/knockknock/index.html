Knock Knock

Knock Knock is a mood check-in app that turns a daily emotional check-in into a short, gentle conversation. Instead of asking you to rate your day on a scale of one to ten, it asks how you are arriving — then helps you find the specific feeling underneath and talk it through.

Tech stack #

  • Frontend: React Native (Expo, SDK 54) · TypeScript · Reanimated · SVG
  • Backend: Cloudflare Workers (serverless AI proxy) · Anthropic Claude API · KV (rate limits)
  • Data: on-device only (AsyncStorage) — no accounts, no server DB
  • Delivery: EAS Build + OTA (EAS Update)

Key Features #

  • Tap anywhere to start a check-in, so the whole ritual stays under a minute
  • A wide vocabulary of emotions, from Joyful and Inspired through Lonely and Discouraged (pick up to two)
  • Context tagging — who you were with and where you were
  • An AI conversation that reflects back what you shared and asks one honest follow-up
  • Generates a personalized reflection/prayer and a relevant passage from what you shared
  • Memory across check-ins — the AI recalls your recent week so replies stay in context
  • Free-writing space for anything the tags could not hold
  • A running history of past check-ins, each entry colored by the mood it recorded

Screens #

The home screen opens with an invitation rather than a form. Recent check-ins stack underneath it, each one tinted by the feeling it recorded, so a week of moods reads at a glance before you have opened a single entry.
